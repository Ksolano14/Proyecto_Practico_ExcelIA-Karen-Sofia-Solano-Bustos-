# Proyecto Final: Análisis de Ventas con Excel + IA

## Descripción del Proyecto
Este proyecto tiene como objetivo analizar datos de ventas utilizando Excel junto con herramientas de Inteligencia Artificial para generar insights, optimizar la toma de decisiones y visualizar la información mediante un dashboard interactivo.

---

## Objetivos
- Limpiar y organizar datos de ventas
- Analizar patrones de comportamiento
- Identificar productos más vendidos
- Crear un dashboard interactivo
- Aplicar herramientas de IA en Excel

## Herramientas Utilizadas
- Microsoft Excel
- Power Query
- Funciones (SUMA, tablas, etc.)
- IA en Excel (Analizar datos / Copilot)

---

## Proceso de Limpieza de Datos
Se realizaron las siguientes acciones:
- Eliminación de datos inconsistentes
- Validación de valores numéricos
- Organización en formato tabla
- Estandarización de categorías

---

## Análisis Realizado
- Ventas totales por producto
- Comparación entre categorías
- Identificación de productos más rentables

---

## Dashboard
El dashboard incluye:
- Gráfico de ventas por producto
- Indicadores clave (KPIs)
- Visualización clara y organizada

---

## Uso de Inteligencia Artificial
Se utilizaron herramientas de IA en Excel para:
- Generar insights automáticos
- Detectar patrones en los datos
- Facilitar el análisis

---

## Reflexión Ética
El uso de inteligencia artificial debe ser responsable:
- Validar siempre los resultados generados
- Evitar dependencia total de la IA
- Considerar posibles sesgos en los datos
